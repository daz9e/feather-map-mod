# World Map

Пергаментная карта мира для Minecraft: текстурный рендер, миникарта, метки, навигация, общие метки и телепорт на серверах.

Мод работает и в одиночной игре, и на серверах без мода. Если мод стоит на сервере, появляются общие метки, позиции игроков, пинги и телепорт по карте.

## Управление

- `M`: открыть карту
- `N`: компас
- `B`: новая метка в текущей точке

## Сервер

Настройки лежат в `config/worldmap-server.json`, общие метки хранятся в мире (`worldmap_marks.json`). Команда `/worldmap reload` перечитывает настройки (нужны права оператора).

| Параметр                  | По умолчанию | Описание                                       |
|---------------------------|--------------|------------------------------------------------|
| `teleport`                | `op`         | кто может телепортироваться: `all`, `op`, `none` |
| `teleportCooldownSeconds` | `10`         | перезарядка телепорта (на операторов не действует) |
| `publicMarks`             | `all`        | кто может создавать общие метки: `all`, `op`   |
| `sharePlayerPositions`    | `true`       | показывать игроков на карте                    |
| `pings`                   | `true`       | разрешить пинги                                |
| `maxPublicMarks`          | `500`        | лимит общих меток                              |

## Разработка

Один исходник собирается под все версии и лоадеры с помощью [Stonecutter](https://stonecutter.kikugie.dev/). Код, зависящий от версии, размечен комментариями `//? if ...`.

```
src/main/java/dev/daze/worldmap/
├── platform/           # всё, что зависит от лоадера
│   ├── Platform.java   # интерфейс: конфиги, отправка пакетов
│   ├── fabric/         # точки входа Fabric
│   ├── neoforge/       # точки входа NeoForge
│   └── forge/          # точки входа Forge (только 1.20.1)
├── client/             # клиент: экран карты, HUD, тайлы, метки
├── Compat.java         # различия API Minecraft (общая часть)
├── Net.java            # канал worldmap:net
└── ServerMap.java      # серверная логика
```

- `stonecutter.properties.toml`: версии зависимостей и диапазоны совместимости для каждой пары «версия + лоадер».
- `settings.gradle.kts`: список собираемых вариантов.
- `build.{fabric,neoforge,forge}.gradle.kts`: сборка под каждый лоадер. В каждом варианте компилируется только своя папка `platform/<лоадер>`.

### Сборка

Gradle запускается на JDK 25 (её требует Loom для 26.x). JDK 17/21 для старых версий Gradle скачает сам (foojay); локальные пути можно указать в `~/.gradle/gradle.properties` через `org.gradle.java.installations.paths`.

```sh
./gradlew buildAll                    # все варианты → build/libs/<версия мода>/
./gradlew :1.21.1-fabric:build        # один вариант
./gradlew :1.21.1-neoforge:runClient  # запуск клиента
./gradlew :1.21.1-fabric:runClient -Pdemo=sp   # демо-сценарий со скриншотами
```

### Активная версия

В исходниках «раскомментирован» код одной версии (сейчас `1.20.1-fabric`, задаётся в `stonecutter.gradle.kts`). Чтобы работать в IDE с другой версией, переключи её задачей `Set active project to <версия>` из группы `stonecutter`. Перед коммитом верни `1.20.1-fabric` (`Reset active project`), иначе диф затронет все версионные комментарии.

### Новая версия Minecraft

1. Добавь `match(...)` в `settings.gradle.kts`.
2. Добавь секции `[fabric."x.y"]` / `[neoforge."x.y"]` в `stonecutter.properties.toml`.
3. Поправь код под изменения API условиями `//? if >=x.y`, общие замены вынеси в `stonecutter.gradle.kts`.
